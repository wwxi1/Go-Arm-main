# 天空块机构控制工程架构设计

## 动力源
1. GO-M8010-6宇树电机
2. AK-80-6
3. 气缸电磁阀

## 模式设计
1. 抓取模式
2. 放置模式
3. 搬运（复位）模式
4. 校准模式（归0重置误差）
5. 夹爪开闭

开机执行初始化和自检程序，2个电机回到初始位置。

### 1.抓取模式
转2->转1
转到抓取前方地面上天空块的位置

### 2.放置模式
转2->转1
转到放置天空块的位置

### 3.搬运模式
转2->转1
转到搬运时的位置

## 实现方案

1. 实现电机驱动和电磁阀驱动
2. PID调参
3. 夹爪松紧调参
4. 电机位置调参

执行任务时间表：
1. 实现电机驱动和电磁阀驱动 8/24
2. PID调参和代码编写 8/25
3. 夹爪松紧调节和电机位置调参 8/26-8-27

## 代码架构：
1. 5个模式写一个状态机，状态为全局变量，放到fdCAN接收中断回调中接收
2. 状态机函数以1kHZ运行在定时器中断中
